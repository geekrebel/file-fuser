# File Fuser Buddy

## Project info

A simple Text File Fuser - I needed to fuse thousands of short chat transcripts (.txt), to make it easier to run chats through a semantic analysis tool. 

Future version will allow text to be merged into a JSON file.

There are several ways of editing your application.



## What technologies are used for this project?

This project is built with:

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS
